IGNIX LAUNCHER 0.1.0
====================
Szybki test (wymaga Javy 8+ w systemie): Uruchom_launcher.bat
Dane launchera: %APPDATA%\.ignix  (gra, assety, Java od Mojanga, konta - szyfrowane DPAPI)

Jak to dziala:
 - PLAY: sprawdza update.json (podpisany) -> pobiera IgnixClient.jar + .sig z GitHub Releases,
   potem Java 8 (Mojang jre-legacy), biblioteki, natywki i assety z serwerow Mojanga (SHA-1).
 - Konto offline: dziala od razu (serwery non-premium).
 - Microsoft: dziala dopiero jak Mojang zatwierdzi Twoje Application ID (formularz juz wyslany).
   Do tego czasu pokaze "Mojang hasn't approved Ignix Launcher yet".

EXE (instalator + portable): wrzuc ten folder do repo na GitHubie (np. Patrykv220/ignix-launcher),
Actions -> "Build Ignix Launcher (exe)" -> Run workflow -> pobierz artefakt.

WAZNE - zeby launcher pobral klienta:
 1. W repo ignix-data: Releases -> nowy release z tagiem v0.5.0, dodaj pliki:
      IgnixClient.jar  oraz  IgnixClient.jar.sig  (z versions\ - nazwij .sig dokladnie tak)
 2. update.json: "version": "0.5.0", dodaj "changelog": "..." i podpisz podpisz_dane.bat
